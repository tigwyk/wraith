Why Wraith

Ghostty's fidelity. Windows' own window.

The terminal core is Ghostty's. Everything around it is written in Rust on raw Win32, Direct3D 11 and DirectWrite, with no web view and no runtime.

↺

Shells outlive the window

A background server owns every shell. Close the window, reopen it, and your screens are exactly where you left them. Scrollback survives a server restart too.

▦

Workspaces, tabs, splits

Each workspace groups its own tabs. Split panes any direction, drag tabs to reorder, and the whole layout comes back after a restart.

⚡

Fast, and stays fast

Keystrokes are written before output is parsed, and frames re-shape only what changed. Typing stays quick after millions of lines, even while another pane floods.

◩

Inline images

Photos and agent screenshots render in place through the Kitty graphics protocol: kitten icat, chafa, yazi.

⌘

Command palette

Every action, fuzzy-searchable, with its current key. A workspace picker, scrollback search, and hover feedback on every button.

≡

Ghostty-style config

The same file syntax and key names, the whole Ghostty theme set, keybind sequences like ctrl+a>c, and hot reload on save.

Coding agents

Your agent asks. Wraith finds you.

Run Claude Code in one tab and Codex in another, then go do something else. When an agent in a hidden tab needs an answer, you know within a second.

  • Harness icon and a working spinner on each agent's tab
  • A toast that opens straight to the pane, plus a taskbar flash and badge
  • An Agents list in the sidebar: waiting first, oldest first
  • Hooks for exact state, with passive detection as the fallback
  • wr events --json to script on top of it all

Install

Two minutes, no admin.

One line in PowerShell installs the latest release. It copies Wraith to %LOCALAPPDATA%\Programs\Wraith, puts wr on your PATH, and adds the Start Menu shortcut toasts need. Prefer the zip? Unpack it and run .\install.ps1.

PS> irm https://tigwyk.github.io/wraith/install.ps1 | iex
PS> wr config check          # %APPDATA%\wraith\config
